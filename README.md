# Финальный тест курса frontend

Небольшое веб-приложение для итогового тестирования. Участник регистрируется, проходит 35 вопросов, ответы сохраняются по ходу попытки. Переключение вкладки или сворачивание окна фиксируется и вызывает предупреждение при возвращении.

## Запуск

1. Установить Node.js 20.19 или новее.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env` и заполнить `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` и `ADMIN_PASSWORD`.
4. Для production выполнить `npm start`, затем открыть `http://localhost:4173`.

Для разработки запустите `npm run api` и `npm run dev` в двух терминалах. Интерфейс откроется на `http://localhost:5173`, API останется на порту `4173`.

Таблицы в Turso создаются сервером автоматически. Секрет доступа к базе используется только на сервере и не передаётся браузеру.

## Проверка работ

Откройте `/admin` и войдите с паролем из `ADMIN_PASSWORD`. Попытки разложены по группам 15:00 и 17:00. Можно сохранять частичные отметки и продолжить проверку позже. После оценки всех пяти открытых ответов откроется общий результат по всем 35 вопросам. Доступ к административным API закрыт серверной сессией.

## Данные

Сохраняются имя, фамилия, период обучения, ответы, время начала и отправки теста, а также события переключения вкладки. Ответы на вопросы с выбором проверяются автоматически. Свободные ответы сохраняются для ручной проверки.

Обычная веб-страница может заметить скрытие своей вкладки/окна, но не может запретить использование второго устройства или отдельной программы.
